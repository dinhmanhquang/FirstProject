### 5.2 User flows chính

**Flow A — Kết nối kênh**
1. MANAGER vào `/channels`, bấm "Kết nối kênh".
2. Dialog liệt kê 5 nền tảng với capability và ghi chú ("TikTok: chỉ đăng bài").
3. Chọn nền tảng → trình duyệt chuyển tới `/api/social-accounts/connect/<platform>` → OAuth nền tảng.
4. Quay về `/channels?connected=N` → toast "Đã kết nối N kênh." → card kênh hiện `ACTIVE`.

**Flow B — Từ trend ra bài đăng**
1. Worker `refresh-trends` chạy 6 giờ / lần; trend relevance ≥ `trends.minRelevanceToNotify` → Telegram.
2. EDITOR vào `/trends`, xem card có điểm liên quan, tóm tắt, 3 góc tiếp cận.
3. Bấm "Tạo bài từ trend" → chọn nền tảng → gọi `POST /api/trends/[id]/ideas` → chuyển tới `/content/new?trendId=` với store đã nạp variants.
4. Chỉnh sửa, thêm media, chọn CTA link, bấm "Lên lịch" → chọn giờ → `POST /api/posts` rồi `POST /api/posts/[id]/schedule`.
5. Trend đổi `USED`. Worker publish đúng giờ. Kết quả từng kênh hiện ở `/content/[postId]`.

**Flow C — Comment vào inbox và trả lời**
1. Webhook / poll đưa comment vào `Interaction` `OPEN`.
2. Worker `classify-and-reply`: phân loại intent, sentiment; áp `decideAutoReply()`.
3. `AUTO_SAFE` và đủ điều kiện → gửi tự động, status `REPLIED`, mode `AUTO`.
4. Không đủ điều kiện → tạo draft `AI_ASSISTED`; nếu `escalate` → `ESCALATED` + Telegram.
5. EDITOR mở `/inbox`, chọn interaction, thấy draft, sửa, bấm "Gửi" → `POST /api/inbox/[id]/reply`.

**Flow D — Seeding bán tự động**
1. MANAGER tạo campaign (mục tiêu, CTA link), thêm target (group, nền tảng, người phụ trách).
2. Bấm "Sinh nội dung" → chọn bài gốc hoặc nhập brief → worker sinh 1 biến thể / target, mỗi task có short link riêng.
3. Người phụ trách nhận Telegram, vào `/seeding`, thấy task `TODO`, bấm "Sao chép nội dung" + "Sao chép link", đăng tay lên group.
4. Dán URL bài đã đăng vào "Bằng chứng", bấm "Đã đăng" → `DONE`.
5. Click qua short link đếm về task và campaign → xem ở chi tiết campaign.

**Flow E — Điều hướng qua Link Hub**
1. EDITOR tạo các Link (Shop TikTok, Nhóm Zalo, Fanpage) ở `/links`.
2. Tab "Link Hub": đặt slug, tiêu đề, thêm item theo thứ tự → Lưu.
3. Dán `/hub/<slug>` vào bio TikTok / Instagram / YouTube. Mỗi click ghi `LinkClick` với `platformHint`.
4. `/analytics` tab Funnel hiện reach → engagement → click → hub click.

### 6.2 Domain components

**Channels**
- `ChannelCard` (`channels/channel-card.tsx`): props `account: SocialAccountItem; canManage: boolean; onSync; onDisconnect`. Hiện badge status (ACTIVE xanh, TOKEN_EXPIRED vàng "Hết hạn token — kết nối lại", ERROR đỏ + `lastError`, DISCONNECTED xám), `lastSyncedAt` relative ("5 phút trước"), danh sách capability dạng chip.
- `ConnectChannelDialog` (`channels/connect-channel-dialog.tsx`): props `open; onOpenChange`. 5 hàng nền tảng, mỗi hàng: icon, tên, ghi chú capability, nút "Kết nối" → `window.location.href = /api/social-accounts/connect/<platform>`.

**Trends**
- `TrendCard`: props `trend: Trend; onCreatePost(trend); onIgnore(trend)`. Điểm ≥ 80 badge xanh, 60–79 vàng, < 60 xám, `null` "Chưa chấm".
- `TrendFilters`: props `value: { source?; minRelevance; status }; onChange`.

**Content**
- `PostEditor` (`content/post-editor.tsx`): props `mode: "create" | "edit"; postId?: string; accounts: SocialAccountItem[]; links: Link[]`. Dùng `usePostEditorStore`, `usePosts()` (mutations). Events: `onSaveDraft`, `onSchedule(scheduledAt)`, `onPublishNow`. Trước khi gọi API: chạy `validateVariantsClient()` → hiển thị lỗi inline dưới textarea từng variant.
- `VariantEditor`: props `variant: EditorVariant; limits: { maxChars; maxHashtags; maxMedia }; requireTitle: boolean; requireMedia: boolean; media: Media[]; onChange(patch)`. Hiện bộ đếm `len/max`, đỏ khi vượt.
- `MediaUploader`: props `value: string[]; onChange(ids); max: number; accept: "image" | "video" | "both"`. Upload qua `POST /api/media`, hiện progress, thumbnail, nút xóa.
- `AiGenerateDialog`: props `open; onOpenChange; platforms: Platform[]; products: Product[]; links: Link[]; onApply(variants: GeneratedVariant[])`. Form: brief (textarea), tone (select 4 giá trị, label tiếng Việt: Thân thiện / Bắt trend / Chuyên nghiệp / Khẩn cấp), sản phẩm (multi-select ≤ 3), hashtag (switch). Nút "Sinh nội dung" → loading "AI đang viết…" → preview từng nền tảng → "Áp dụng".
- `ScheduleDialog`: props `open; onOpenChange; value: string | null; onConfirm(iso)`. Calendar + input giờ (bước 5 phút) theo giờ VN; gợi ý 3 khung giờ cố định: 08:00, 12:00, 20:00.
- `PostStatusBadge`: props `status: PostStatus`. Màu: DRAFT xám, SCHEDULED xanh dương, PUBLISHING vàng (spinner), PUBLISHED xanh lá, PARTIALLY_FAILED cam, FAILED đỏ.
- `PostTable`: props `rows: PostListItem[]; meta; onPageChange; onRowClick`.

**Calendar**
- `CalendarGrid`: props `month: string (YYYY-MM); posts: PostListItem[]; onSelectDay(date); onSelectPost(id); onMonthChange(month)`. 7 cột, bắt đầu Thứ 2. Mỗi ô ≤ 3 bài + "+N".

### 6.6 Platform adapters (`src/lib/platforms/*`)

Mọi adapter implement `PlatformAdapter` (types). HTTP dùng `fetch` toàn cục, timeout 30 giây qua `AbortSignal.timeout(30_000)`. Lỗi HTTP → `PlatformError(platform, code, message, retryable)` với `retryable = status >= 500 || status === 429`. Token hết hạn (Facebook code 190, Zalo -216, TikTok `access_token_invalid`, YouTube 401) → `PlatformError(..., "TOKEN_EXPIRED", ..., false)` và caller đặt `SocialAccount.status = TOKEN_EXPIRED`.

Processor `classify-and-reply`: nạp interaction (status OPEN, chưa `classifiedAt`) → `classifyInteraction` → lưu intent/sentiment/confidence/escalate/classifiedAt → `escalate === true` → `escalate()` → `matchTemplate` → `decideAutoReply` → SEND: nội dung = template hoặc `draftReply()`, `sendReply(..., "AUTO", null)`; DRAFT: tạo `Reply` DRAFT `AI_ASSISTED` với `draftReply()` (khi interaction không SPAM); SKIP: không làm gì → phát `RuleEvent` `NEW_COMMENT` / `NEW_MESSAGE` với payload `{ platform, content, intent, sentiment, fanId, fanScore }`.

Mỗi processor: ghi `JobRun` RUNNING khi bắt đầu, COMPLETED/FAILED khi kết thúc; log pino.
