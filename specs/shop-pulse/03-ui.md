## [5] UI/UX Specification

### 5.1 Bảng routes

| path | page component | auth | mục đích |
|---|---|---|---|
| `/login` | `src/app/(auth)/login/page.tsx` | Không | Đăng nhập email + mật khẩu |
| `/` | `src/app/(app)/page.tsx` | STAFF | Dashboard: tổng quan hôm nay |
| `/shops` | `src/app/(app)/shops/page.tsx` | STAFF | Danh sách shop, lọc, tìm |
| `/shops/new` | `src/app/(app)/shops/new/page.tsx` | MANAGER | Tạo shop |
| `/shops/[shopId]` | `src/app/(app)/shops/[shopId]/page.tsx` | STAFF | Chi tiết shop: score, bảng chỉ số, xu hướng, nhiệm vụ |

| `/tasks` | `src/app/(app)/tasks/page.tsx` | STAFF | Danh sách nhiệm vụ có bộ lọc |
| `/tasks/[taskId]` | `src/app/(app)/tasks/[taskId]/page.tsx` | STAFF | Chi tiết + cập nhật nhiệm vụ |
| `/notifications` | `src/app/(app)/notifications/page.tsx` | STAFF | Danh sách thông báo |
| `/settings/thresholds` | `src/app/(app)/settings/thresholds/page.tsx` | MANAGER | Ngưỡng chỉ số |
| `/settings/rules` | `src/app/(app)/settings/rules/page.tsx` | MANAGER | Quy tắc sinh nhiệm vụ |
| `/settings/members` | `src/app/(app)/settings/members/page.tsx` | MANAGER | Thành viên |

Trang yêu cầu MANAGER mà user là STAFF: `(app)/settings/layout.tsx` và 2 page shop MANAGER kiểm tra `session.role`, nếu STAFF → `redirect("/?denied=1")`; `(app)/layout.tsx` đọc `denied=1` và hiển thị toast `errors.forbidden` một lần.

Tạo nhiệm vụ thủ công: không có route riêng; `TaskForm` mở trong `Sheet` từ nút "Tạo nhiệm vụ" ở `/tasks` và ở `/shops/[shopId]`.

### 5.3 User flows

**Flow 1 — Nhân viên bắt đầu ngày**

1. Mở `/` → thấy `StaleShopsAlert` nếu có shop chưa nhập chỉ số hôm nay.
2. Bấm "Nhập ngay" trên 1 shop → `/shops/[id]/metrics`, ngày = hôm nay, form điền sẵn giá trị ngày gần nhất.
3. Sửa các ô thay đổi → bấm "Lưu chỉ số".
4. Panel kết quả hiện: Health Score mới, status, danh sách nhiệm vụ vừa sinh (nếu có), nút "Xem nhiệm vụ" và "Nhập shop tiếp theo" (shop ACTIVE kế tiếp chưa nhập hôm nay; ẩn khi không còn).
5. Quay lại `/` → `TodayTasksPanel` liệt kê việc hôm nay theo ưu tiên.

**Flow 2 — Xử lý nhiệm vụ**

1. Ở `/tasks` hoặc `TodayTasksPanel`, bấm 1 nhiệm vụ → `/tasks/[id]`.
2. Đọc mô tả có "Việc cần làm" (action hint) và link "Mở shop".
3. Chọn "Đang làm" → làm việc trên Seller Center.
4. Quay lại, chọn "Hoàn thành", ghi chú kết quả, bấm "Cập nhật".
5. Nếu không làm được: chọn "Bỏ qua", ghi lý do (bắt buộc) → "Cập nhật".

**Flow 3 — Import CSV nhiều ngày**

1. `/shops/[id]/import` → bấm "Tải file mẫu" (link `/templates/metrics-template.csv`).
2. Điền file, chọn file → preview 20 dòng đầu, số dòng, số lỗi phát hiện phía client (cùng `parseMetricsCsv`).
3. Bấm "Import" → kết quả: thành công / lỗi / ngày ảnh hưởng / nhiệm vụ sinh ra.
4. Bấm "Xem shop" → `/shops/[id]`.

**Flow 4 — Trưởng nhóm tinh chỉnh**

1. `/settings/thresholds` → sửa inline ngưỡng và trọng số → "Lưu thay đổi".
2. `/settings/rules` → bật / tắt rule, sửa template, thêm rule ROUTINE mới.
3. `/settings/members` → tạo tài khoản STAFF, gán shop trong `/shops/[id]/edit`.

**Flow 5 — Tạo shop mới**

1. `/shops` → "Thêm shop" → `/shops/new`.
2. Chọn sàn, nhập tên, chọn người phụ trách → "Tạo shop".
3. Redirect `/shops/[id]/metrics` với banner "Nhập chỉ số đầu tiên để bắt đầu theo dõi".

## [6] Component & Logic Specifications

Quy ước: mọi component là function component, file `.tsx`, export default; props khai báo `interface <Name>Props`. Component cần state client có `"use client"` ở dòng đầu. Page trong `(app)` là Server Component gọi `auth()` để lấy session rồi render client component.

### 6.1 common

**`src/components/common/PageHeader.tsx`**

```ts
interface PageHeaderProps { title: string; description?: string; backHref?: string; actions?: React.ReactNode }
```

Render `<h1 className="text-2xl font-semibold">`, link quay lại (icon `ArrowLeft`, `aria-label` = `common.back`) khi có `backHref`.

**`src/components/common/EmptyState.tsx`**

```ts
interface EmptyStateProps { icon: LucideIcon; title: string; description?: string; action?: { label: string; href?: string; onClick?: () => void } }
```

**`src/components/common/StatusPanel.tsx`**

```ts
interface StatusPanelProps { state: "loading" | "error"; skeleton?: React.ReactNode; onRetry?: () => void; message?: string }
```

`loading` → render `skeleton` hoặc 3 dòng `Skeleton`. `error` → `Alert variant="destructive"` với `message ?? t("errors.loadFailed")` và nút `common.retry`.

**`src/components/common/ConfirmDialog.tsx`**

```ts
interface ConfirmDialogProps { open: boolean; title: string; description: string; confirmLabel: string; destructive?: boolean; loading?: boolean; onConfirm: () => void; onOpenChange: (open: boolean) => void }
```

### 6.2 layout

**`AppSidebar.tsx`** — props `{ role: Role }`. Hooks: `usePathname`, `useUiStore`. Mục Cài đặt chỉ khi `role !== "STAFF"`.

**`AppHeader.tsx`** — props `{ user: SessionUser; orgName: string }`. Chứa `NotificationBell` và `DropdownMenu` user. Event: "Đăng xuất" → `signOut`.

**`NotificationBell.tsx`** — không props. Hook `useNotifications({ limit: 5, unread: true })`. Hiển thị badge `unreadCount` (ẩn khi 0, hiện `9+` khi > 9). Click mở `DropdownMenu` 5 thông báo mới nhất + link `/notifications`. Click 1 thông báo → gọi `markRead([id])` rồi `router.push(link)`.

### 6.3 dashboard

**`SummaryCards.tsx`** — props `{ counts: DashboardSummaryDto["counts"] }`. 4 `Card`, mỗi card: nhãn (`dashboard.counts.<key>`), số, viền màu theo status (00-overview §7.6). Click card → `/shops?health=<STATUS>` (query chỉ dùng phía client để lọc).

**`ShopHealthGrid.tsx`** — props `{ shops: ShopDto[]; onlyMine: boolean; currentUserId: string }`. Lọc `assignee.id === currentUserId` khi `onlyMine`. Grid `ShopCard`. Empty → `EmptyState` `dashboard.empty`.

**`TodayTasksPanel.tsx`** — props `{ dueToday: TaskDto[]; overdue: TaskDto[] }`. 2 nhóm, mỗi nhóm tối đa 10 `TaskItem` (compact), link "Xem tất cả" → `/tasks?due=today`.

**`StaleShopsAlert.tsx`** — props `{ staleShops: DashboardSummaryDto["staleShops"] }`. Ẩn khi mảng rỗng. Mỗi shop có nút "Nhập ngay" → `/shops/[id]/metrics`. `staleDays = -1` hiển thị `dashboard.stale.never` "chưa có dữ liệu"; ngược lại `dashboard.stale.days` "{n} ngày".

### 6.4 shops

**`ShopCard.tsx`** — props `{ shop: ShopDto }`. Hiển thị: badge sàn (`Shopee` / `TikTok Shop`), tên (link `/shops/[id]`), `score` lớn, `ShopStatusBadge`, "Cập nhật: hôm nay / {n} ngày trước / chưa có", `openTaskCount` việc mở, tên người phụ trách.

**`ShopStatusBadge.tsx`** — props `{ status: HealthStatus; size?: "sm" | "md" }`. Text: HEALTHY `Ổn định`, WARNING `Cảnh báo`, CRITICAL `Nguy cấp`, NO_DATA `Chưa có dữ liệu`. Có `role="status"`.

**`HealthGauge.tsx`** — props `{ score: number; status: HealthStatus; updatedLabel: string }`. Vòng SVG bán kính 56px, stroke màu theo status, số ở giữa `text-4xl`. `aria-label` = "Health Score {score} trên 100".

**`MetricBreakdownTable.tsx`** — props `{ breakdown: MetricEvaluation[]; catalog: CatalogItemDto[] }`. Cột: Chỉ số, Giá trị (format theo `decimals` + `unitLabel`), Ngưỡng CB, Ngưỡng NC, Mức (badge OK / Cảnh báo / Nguy cấp). Sắp: CRITICAL → WARNING → OK, rồi theo thứ tự catalog.

**`MetricTrendChart.tsx`** — props `{ shopId: string; platform: Platform; catalog: CatalogItemDto[]; thresholds: ThresholdDto[] }`. State nội bộ `selectedKey` (mặc định chỉ số có `defaultWeight` cao nhất, đầu tiên theo catalog). Hook `useMetrics(shopId, { from: today-29, to: today })`. Recharts `LineChart` + 2 `ReferenceLine` (warning `#D97706`, critical `#DC2626`). Ngày không có dữ liệu → gap (`connectNulls={false}`).

**`ShopForm.tsx`** — props `{ mode: "create" | "edit"; initial?: ShopDto; members: UserDto[]; onSuccess: (shop: ShopDto) => void }`. ### 6.5 metrics
